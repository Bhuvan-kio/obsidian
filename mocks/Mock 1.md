# Mock Interview Set 1

## Question 1

**Problem**

> Given an array, find two numbers whose sum is equal to the target.

### Expected Pattern

```
Hash Map
```

### Clues

- Pair
- Sum
- Target
- Return indices

### Data Structure

```
Dictionary
```

### Time Complexity

```
O(n)
```
